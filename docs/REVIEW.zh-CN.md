# 离线审阅与多工况对比

0.4.0 新增“自动 / 移动审阅 / 桌面审阅”，支持触控与工况、截面、附加图层按需加载。电脑上已拼好的左右半车 HTML 可以交给平板在一个画布中展示。详见[平板指南与实体设备验证边界](MOBILE_REVIEW.md#平板与移动审阅)。

[English](REVIEW.md) · [安装指南](INSTALL.zh-CN.md)

新安装的软件和新报告默认英文。桌面顶部或 HTML 的 **“更多”** 菜单可选择 **简体中文**；桌面记住本地偏好，导出的 HTML 与工程 JSON 保存各自选择。切换语言保留工况、视角、截面、色标、图层和批注。源对象名、场函数名、标题和用户文字保留原文；自定义模板的文段由使用者自行提供双语内容。

StarCapsule Studio 的桌面程序负责从本机 STAR 导出数据；导出的 HTML 负责查看、对比、调整显示和保存批注。HTML 自带模型、场值、模板素材与渲染引擎，复制到其他设备后，在支持本地 JavaScript 和 WebGL 的环境中打开。

大数据报告默认使用无损 gzip 封装；新版 HTML 优先原生解压，缺少接口时使用内嵌离线解压组件。源网格、截面及数值精度保留；加载完成后释放冗余数据文本。多工况仍需足够的内存与 GPU 资源，文件压缩比例不等于运行内存缩减比例。

旧 HTML 内嵌旧版代码。更新桌面软件后，使用 `starcapsule upgrade 旧报告.html --output 新报告.html` 另存更新，或在新版查看器追加导入旧报告，再导出 HTML。无需重跑 STAR；源文件默认保留。安装后的新命令为 `starcapsule` 和 `starcapsule-gui`，原 `cfd-review` / `cfd-review-gui` 命令继续可用。

桌面导出时，Cp 仅选择可用的 `PressureCoefficient`，CpT 仅选择可用的 `TotalPressureCoefficient`，也可选择“不导出”。压力、Q 等其他有效标量在“已有后处理”的图层着色中选择，并使用各自的名称和单位。

## 加入更多工况

顶部合并项目与对比操作；工况选择与相机工具共用一行。“视角”菜单提供等轴、俯视、沿 X/Y 和完整截面；工况三点菜单提供重命名、来源摘要与批注。“更多”包含报告名称、语言、审阅模式和保存工程。取点读数以画布内的高亮浮层显示。

“A/B 联动”控制两个可见视口之间的视角、X 坐标、场量和色标同步。只有一个可见视口时，开关禁用并保留已存偏好。取消勾选会停止后续同步，不会隐藏元素或撤销当前画面；重新开启会以 A 对齐 B。

打开第一份报告，点击顶部 **“导入 HTML / 数据”**。选择另一份由 StarCapsule Studio 导出的 HTML，或单个工况 JSON，即可追加到当前工况库。重复操作可加入更多来源；显示时在 A/B 下拉框选择任意两个工况。

| 选择的文件 | 导入后的行为 |
| --- | --- |
| 导出的 `.html` / `.htm` | 追加其中尚未加入的工况，保留当前窗口的标题、模板和已有工况；新增工况的已保存视图及相关批注可随数据加入 |
| 单个 `case.json` | 追加一个独立工况，保留当前工程 |
| `project.json` | 恢复该完整工程，替换当前工程及其视图、批注和界面设置 |
| `.sim` | 先在本机桌面程序通过兼容且已许可的 STAR 导出 HTML 或工况 JSON |

已有相同工况 ID 且来源相同的数据保留当前版本；同一 ID 指向不同来源时，软件提示在导出端设置独立 ID。追加导入用于增加工况，完整恢复已保存状态时可直接打开那份 HTML，或导入其工程 JSON。

导入 HTML 时只提取并校验已知的数据槽，沿用当前窗口的引擎与模板。导入页中的脚本、CSS、图片元素等外层网页内容不会执行或加入当前窗口。自定义外观通过桌面程序 **“选择模板…”** 明确设置，详见[模板规范](TEMPLATES.md)。

## 选择对比方式

### 单个工况镜像显示整车

右侧设置顶部的 **“镜像显示整车”** 用于在 Y=0 两侧显示同一个对称半车的结果。源文件已声明为 Y=0 半车时可直接使用；漏选半车标记的源，先在左侧工况库确认半车，再启用右侧镜像开关。关闭后回到原始半车显示。

表面、截面和三维图层同步镜像，沿用原始颜色、透明度和显隐设置。镜像侧取点同时保留显示位置与原始位置；开关随视图、批注和导出 HTML 保存。它是对称结果的显示映射，原始源数据保持一致。A/B 拼接已显示两个独立工况，使用原有拼接模式查看。

左侧半车确认负责源数据声明，右侧镜像开关负责当前视口的显示。已保存的镜像批注会保留其所需的半车声明。

### 并排对比

点击 **“并排对比”**，在两个视口顶部的 A/B 下拉框选择来源。这个方式适用于完整模型及半模型，允许两个来源拥有不同的截面数量。

顶部 **“A/B 联动”** 菜单中的“视角”“X 坐标”“场量”“色标”可以分别联动。X 联动以物理坐标定位到另一来源最近的实际导出面，并显示所选真实位置；它不生成新的截面。对比前核对坐标原点、轴向、单位，以及 Cp/CpT 的参考定义，使两侧表达同一物理含义。

### 同画布半车拼接

选择两个实际以 Y=0 为对称面的半模型，指定 A 为 −Y 侧、B 为 +Y 侧，再点击 **“拼接到同一画布”**。两半共用一个相机，显示坐标的反射映射和每个三角面的原始来源分别保留。工况库继续保留两个原始来源及新增的派生拼接工况。

若真实半模型在导出时漏选了半车标记，可在工况库勾选 **“我确认源数据为 Y=0 对称半车”**。这是使用者对源模型物理对称性的明确确认；软件同时检查导出几何位于 Y=0 单侧。跨越 Y=0 两侧的完整几何无法据此声明为半车。

声明记录原来的半车/轴向元数据及确认时间，只更新半车声明和 Y 轴信息，保持几何、原始场值、来源标识和 `scalarMirror` 原值。单个来源的整车镜像由右侧开关控制。加入拼接前、关闭镜像显示且没有镜像批注引用时，可取消声明并恢复原元数据；已被拼接或镜像批注引用时保留声明，恢复相应操作前的工程后可撤销。

拼接和内部编辑快照保留源数值数组，按需创建显示反射所需的几何，减少整个工程的重复复制。原始工况持续保留，取点、批注和显示设置分别记录。浏览器与 GPU 仍需为当前画面分配资源，实际可处理规模同时受系统可用内存和浏览器资源约束。

共同截面按双方 **实际相同的 X 坐标** 和共同字段建立。片数一致只是数量一致，无法替代坐标对应；片数不同的来源也可能拥有部分共同 X 面。

| 共同 X 截面 | 同画布可查看的内容 |
| --- | --- |
| 0 个 | 两半表面、部件和已导出的三维图层 |
| 1 个 | 上述内容，以及这一个固定位置的截面对照 |
| 至少 2 个 | 上述内容，以及共同真实截面之间的空间扫掠 |

需要连续的同画布对比时，在桌面导出阶段为两个来源使用相同的实际 X 列表。表面和既有三维图层对比可先使用当前数据。

## 调整颜色与透明背景

表面 Cp、截面 Cp/CpT 和有标量的三维图层各有色标上下限。输入数值后点击对应 **“应用”**，配色即时更新；“恢复默认”恢复该数据来源的初始显示范围。超出色标范围的数值使用端点颜色，原始数组保持不变。

CpT 截面额外提供 **“CpT≥阈值透明”**。默认阈值为 **0.98**；填写所需的有限数，再点击其“应用”，达到或超过阈值的区域变为透明。关闭勾选可恢复这些区域的着色。阈值可以大于 1 或小于 0，以适应所导出物理量的实际范围。

色标和透明阈值分工不同：色标决定颜色映射，阈值决定高 CpT 区域是否显示；提高色标上限本身不会隐藏背景。透明筛选只作用于 CpT 截面，Cp 截面、表面 Cp 和附加图层保留各自显示控制。双视口中的透明阈值按视图独立保存，需要一致筛选时给两侧填写相同阈值。

## 查看截面、取点和批注

拖动 X 滑块或输入坐标后点击“定位”，可选择最近的已导出截面。HTML 中的 X 控件显示所标注的单位；桌面导出范围使用 m。播放表示不同空间截面的往返变化，保留每个真实导出面；它不是瞬态时间动画。

左键拖动旋转，滚轮缩放，Shift＋左键拖动平移。双击可读取可见三角面上的场值与坐标；启用“取点”模式后也可单击读取。读数来自该原生三角形顶点场的重心插值，几何参照图层只提供位置。半车拼接读数同时保留来源工况、显示位置和反射前的原始位置。

取点读数位于画布内高亮浮层，避免单独占据一行。Cp、CpT 等标量使用独立填色矩形，部件名称与坐标作为次级信息；读数变化不挤压画布。缺测有独立标记，几何图层只显示位置。未命中使用提示色；复位或切换相关截面会清除旧读数。取点、扫掠和色标应用按钮使用蓝色强调，便于快速定位。

右键场景或点击批注按钮，可保存观察说明及对应的相机、截面、场量、阈值、色标、部件/图层设置与取点。恢复批注时，视口回到保存的观察状态。

左侧 **“收起目录 / 展开目录”** 可以为三维画面增加横向空间，收起后保留展开按钮并支持键盘操作。折叠不切换工况，也不改变相机、阈值、取点或批注；右侧科学显示设置独立滚动。

## 保存并转交

点击 **“导出 HTML”**，保存一份新的完整报告。它包含工况库中的全部工况、当前 A/B 选择、显示状态、透明阈值、批注、目录折叠偏好、当前模板和离线依赖。重新打开该文件后，可继续从已有工况中选择 A/B，也可以追加其他报告。

**“保存工程”** 输出工程 JSON，用于在当前软件中恢复和继续编辑；JSON 不携带另一套外观模板。需要转交完整可打开报告时，使用 HTML，并将可编辑的模板文件夹另行保留。

| 边界 | 当前格式上限 |
| --- | --- |
| 完整工程的工况数 | 32 个，包含派生拼接工况 |
| 原始工况的全部数据块合计；单份工程清单 | 分别 500 MiB |
| HTML 中派生拼接索引 | 1 MiB |
| 整份 HTML | 2 GiB |
| 普通 JSON 导入/保存 | 500 MiB，较大的组合工程使用 HTML |

多工况 HTML 使用索引和独立工况数据槽保存。两份原始来源各保存一次，派生半车拼接另存小型来源与设置索引（recipe），避免再次存储完整的组合数组；重新打开时按原始几何、标量和共同真实 X 面重建并核验。旧版存储完整工况的报告保持可读，普通工程 JSON 仍保留原有格式。

较大报告进一步将工况表面、真实截面和符合条件的附加图层分块内嵌。首屏只读取所选工况核心与当前截面，每个驻留工况最多缓存两个解压截面。附加图层开启时加载，隐藏后释放渲染资源及解压工作副本，原压缩数据仍保留用于完整 HTML 保存。“保存工程”会展开完整 JSON，临时内存可能明显高于“导出 HTML”。

执行读取、解压、准备模型/图层和打包时显示任务状态。解压显示实际字节进度，其余阶段使用不定进度，不编造百分比。设备缺少原生 `CompressionStream` 时，编辑后的数据块可能保存为普通 JSON，使文件变大；未查看的 v2 压缩块原样保留。

上述数字是输入/输出校验上限，实际可用规模取决于内存、浏览器/GPU、几何密度、图层数量和同时显示的两个来源。接近格式上限的文件并不代表任意电脑都能流畅查看；软件保留真实数据，不自动降采样。

旧报告更新查看功能时，可使用当前版本重新打包已有数据，无需重跑 STAR：

```powershell
cfd-review upgrade old-review.html --output updated-review.html
```

默认另存新文件，保留源报告。需采用自己的外观时增加 `--template 模板文件夹`；不传模板则使用当前内置布局。新增截面、改变等值面的提取阈值或计算新的流动结构，仍由源仿真提供所需数据并重新导出。

官方程序与导出的 HTML 固定显示 **Designed by Symn**。HTML 的署名显示在当前视口底部已有的状态栏右侧，完整保留画布的垂直空间。模板接口保留该署名；源码的可编辑性与 MIT 许可说明见[项目说明](../README.zh-CN.md)。
