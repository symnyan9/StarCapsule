## 项目介绍

StarCapsule 面向工程方案评审、设计答辩和仿真结果交付。它将已保存 STAR-CCM+ 仿真中的所选几何、场值、真实截面与已有后处理面，封装为独立的三维审阅工作台。接收者打开一个 HTML，即可旋转模型、查看局部数值、扫掠截面、切换方案并记录观察，无需安装 STAR、Python 或服务器。

导出端通过本机兼容且有许可的 STAR-CCM+，在独立后台进程中读取保存状态并提取结果，用户无需手动打开 STAR 图形界面。壁面和新增 X 截面可以根据所选对象从保存场生成；已有等值面和其他受支持的面对象可以直接选择，附带可取得的原始定义信息。必需的网格、求解场与场函数仍需存在于源文件中。

几何、导出数值、来源标识与审阅设置随同一个文件保存，讨论可以回到具体工况、截面、视角和取点位置。追加新的工况、组织对比、留下批注后，再次导出 HTML，即可把这次审阅的上下文一起交给下一位成员。审阅环境随结果交付，降低接收端的软件与操作门槛。

## 核心价值

### 从本地仿真到独立交付

选择 `.sim`，读取对象清单，再选择壁面、系数场、截面和已有后处理图层。软件调用本机 STAR 完成原生导出；导出的 HTML 内置查看所需的三维引擎、界面和数据，查看环节无需 CDN、云账号、AI 服务或本地服务器。

### 让结果可以被继续检查

旋转、缩放、平移和全屏用于查看结构细节；真实 X 截面的手动选择、暂停与自动往返用于追踪流场沿程变化。Cp/CpT 切换、独立色标、CpT 透明阈值和部件显隐可直接在网页中调整。取点显示基于已导出三角面顶点场值的插值结果，并保留对应来源与坐标。

### 把方案放在同一个审阅环境中

同一 HTML 可追加多个工况，在 A/B 视口中自由选择对比来源，并分别控制相机、物理 X 位置、场量与色标的联动。符合坐标与对称条件的两个半模型，还可放在同一画布的两侧，共用相机并保留各自的来源归属。

### 让讨论保留上下文

批注关联对应的观察状态。保存后的 HTML 保留工况库、A/B 选择、视角、截面、图层、色标与批注，重新打开后可以继续审阅。它也可作为一组精选结果的便携目录，用于交接、课堂展示或反复讨论设计迭代。

### 让交付符合自己的表达方式

桌面程序和 HTML 默认英文，可切换为简体中文并保留选择；源对象名称与用户填写的标题保持原文。HTML/CSS 模板提供明确的容器与引擎接口约定，可定制团队或个人外观，官方导出保留小型作者署名 **Designed by Symn**。

### 保留所选细节，减少重复负担

大数据使用 gzip 无损压缩与分块封装，不通过自动减面或小数舍入压缩已导出数据。内部复用未改变的数组，同画布派生对比通过来源组合记录保存，减少不必要的重复复制与存储。实际体积、打开速度和可用工况数量取决于所选几何、截面、图层和设备，不能把文件压缩比例等同于内存节省比例。

## 典型使用场景

- **设计答辩与现场介绍：** 从整体模型切换到真实截面和局部读数，围绕关键证据讲述设计变化。
- **团队方案评审：** 在同一视角、色标和物理位置下比较两个工况，把观察与对应状态一起保存。
- **仿真结果交接：** 向未安装 STAR 的成员交付精选结果，保留来源与可继续操作的审阅界面。
- **离线结果目录：** 将需要共同讨论的若干工况组织为一个文件，在支持的桌面浏览器中重复打开。

## 建议演示路线

1. 选择合成示例，演示模型旋转、局部取点与色标调整。
2. 手动选择真实导出截面，再展示自动往返扫掠和暂停。
3. 追加第二个工况，展示 A/B 联动与满足条件的同画布半模型对比。
4. 添加批注、保存 HTML，再离线重新打开，恢复工况与观察状态。
5. 展示定制模板和语言切换，链接安装、操作及验收说明。

## 功能边界

StarCapsule 是**所选结果的便携快照与审阅工具**。HTML 保存导出的几何、数值和上下文，不保存完整 `.sim` 求解环境，不能替代源仿真备份、重新求解或完整仿真归档。

原生读取仍需兼容的本机 STAR 安装、足够资源和有效许可；是否需要连接许可服务器取决于当地许可配置。当前原生接口已验证的版本为 **STAR-CCM+ 19.02.009**，其他版本需要单独验证。独立 HTML 查看不启动 STAR。

自动往返遍历实际导出的空间截面，不等同于瞬态时间播放或任意位置重新切片。新增截面、修改源等值面阈值或重新计算涡结构，需要重新从保存仿真导出。同画布半模型对比需要可比坐标、真实 Y=0 半模型及可用字段；联动双视口可容纳不同截面数量，实际对应位置会显示。

“保留精度”指保留已导出数据的精度。求解收敛、物理定义、参考量和方案可比性仍需工程人员确认。公开示例为明确标注的合成数据；[验收记录](VALIDATION.md)分别说明合成检查、真实导出与具体设备的测试范围。
